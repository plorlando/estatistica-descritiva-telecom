# Estatística Descritiva — Análise de Clientes de Telecomunicações

## Objetivo
Desenvolver um estudo de Estatística Descritiva utilizando Python para analisar o perfil dos clientes de uma empresa de telecomunicações.

## Dataset
**Telco Customer Churn**, disponibilizado no Kaggle.

Fonte: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Tecnologias
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Conteúdo do estudo
- Análise e classificação de variáveis
- Medidas de tendência central
- Medidas de dispersão
- Quartis e percentis
- Distribuições de frequência
- Identificação de outliers
- Visualização e interpretação estatística
